# BABYLON-INVENTORY-AGENT
## Agente Autónomo de Compra y Gestión de Inventario

Este agente del ecosistema **BABYLON.IA** está estructurado bajo principios de optimización local y diseñado comercialmente para la gestión de recursos de desarrollo y hardware en pymes tecnológicas.

### 🌟 Propuesta de Valor Clave
* **Calendario de Compra Predictivo**: Incorpora el análisis de ciclos comerciales ("Presupuestos en Octubre-Noviembre") para alertar e influenciar las decisiones óptimas de compra de software e infraestructura tecnológica.
* **Control de Costos de Hardware Local**: Gestiona las existencias físicas necesarias para correr agentes locales libres de token-lock (RTX 4090s, SSDs, Nodos locales).
* **Flujos de Re-orden Automatizados**: Redacción instantánea de borradores de órdenes de compra cuando el stock de hardware crítico cae del umbral seguro.

### ⚙️ Funcionalidades
1. **Gestión de Stock de Servidores y Clústers**: Monitoreo dinámico del inventario.
2. **Motor de Compra Programada**: Sugiere compras capitales (CAPEX) en meses de alta conversión fiscal para calzar con los presupuestos anuales corporativos.
3. **Generador de Borradores de Compra**: Redacta emails/documentos listos para enviar al proveedor con un solo clic.

### 🚀 Ejecución
1. Instala dependencias:
   ```bash
   npm install
   ```
2. Inicia:
   ```bash
   npm start
   ```
3. Abre: `http://localhost:4002`
